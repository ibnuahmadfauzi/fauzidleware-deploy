#2. Sintaks Dasar PHP

2.1. Pengertian Sintaks PHP

Sintaks adalah aturan penulisan kode dalam suatu bahasa pemrograman. Setiap bahasa memiliki aturan sintaks yang berbeda, termasuk PHP. Apabila sintaks ditulis dengan benar, program dapat dijalankan dengan baik. Sebaliknya, kesalahan penulisan sintaks (syntax error) akan menyebabkan program gagal dijalankan. Sebagai contoh, program PHP yang benar adalah:

<?php
echo "Hello, World!";

Sedangkan contoh berikut akan menghasilkan kesalahan karena tidak diakhiri dengan tanda titik koma(;)

<?php
echo "Hello, World!"

Oleh karena itu, memahami sintaks dasar merupakan langkah pertama yang harus dikuasai sebelum mempelajari konsep-konsep PHP yang lebih kompleks.



2.2. Tag PHP

Seluruh kode PHP harus ditulis di dalam tag PHP. Tag ini memberi tahu web server bahwa bagian tersebut merupakan kode PHP yang harus diproses.

Tag Pembuka

Tag pembuka yang direkomendasikan adalah:

<?php

Tag Penutup

Tag penutup ditulis sebagai berikut:

?>

Namun, jika file hanya brisi kode PHP tanpa HTML, tag penutup disarankan untuk dihilangkan agar menghindari keluarnya karakter atau spasi yang tidak diinginkan. Contohnya:

<?php
echo "Hello, World!";



2.3. Aturan Penulisan Sintaks PHP

Saat menulis kode PHP, terdapat beberapa aturan yang perlu diperhatikan.

1. Setiap pernyataan diakhiri titik koma

<?php
echo "Hello, World!";
echo "Belajar PHP Dasar";

2. PHP Bersifat Case Sensitive

Nama variabel bersifat sensitif terhadap huruf besar dan kecil. Contohnya $nama berbeda dengan $Nama. Sebaliknya beberapa keyword bawaan PHP seperti echo, if, while, function tidak membedakan huruf besar dan kecil. Meskipun penuisan huruf kecil tetap menjadi standar yang dianjurkan.

3. Spasi tidak berpengaruh

Kode berikut memiliki hasil yang sama:

<?php
echo       "Hello, World!";

<?php
echo "Hello, World!";

Walaupun demikian, gunakan indentasi spasi yang rapi agar kode mudah dibaca.



2.4. Komentar pada PHP

Komentar adalah bagian kode yang tidak akan dijalankan oleh program. Komentar digunakan untuk memberikan penjelasan kepada programmer lain maupun kepada diri sendiri. PHP menyediakan tiga jenis komentar:

1. Komentar satu baris menggunakan //

<?php
// menampilkan teks
echo "Hello, World!";

2. Komentar satu baris menggunakan #

<?php
# menampilkan teks
echo "Hello, World!";

3. Komentar banyak baris

Digunakan untuk membuat dokumentasi atau menjelaskan bagian program yang cukup panjang.

<?php
/*
    file PHP pertama
    ditulis oleh:
    Ibnu Ahmad Fauzi
*/
echo "Hello, World!";
