#3. Variabel PHP

3.1. Pengertian Variabel

Variabel adalah sebuah tempat di dalam memori komputer yang digunakan untuk menyimpan suatu nilai atau data. Data yang disimpan pada variabel dapat berupa teks, angka, nilai logika (boolean), maupun tipe data lainnya. Dengan menggunakan variabel, kita tidak perlu menuliskan nilai yang sama berulang kali sehingga program menjadi lebih rapi, mudah dibaca, dan mudah dikelola.

Sebagai contoh, jika sebuah program menyimpan nama pengguna "Ibnu Ahmad Fauzi", maka nama tersebut cukup disimpan dalam sebuah variabel. Ketika nilai tersebut diperlukan, kita hanya perlu memanggil nama variabelnya tanpa harus menuliskan kembali isi datanya.



3.2. Membuat Variabel

Dalam PHP, setiap variabel selalu diawali dengan tanda dolar ($) yang diikuti dengan nama variabel. Struktur umumnya

$nama_variabel = nilai; Contohnya:

<?php
$nama = "Ibnu Ahmad Fauzi";
echo $nama;

3.3. Menampilkan Nilai Variabel

Nilai yang telah disimpan dalam variabel dapat ditampilkan menggunakan echo atau print.

Contohnya:

<?php

echo "<h1>Selamat Datang, ", $nama, "</h1>";

3.4. Mengubah Nilai Variabel

Nilai sebuah variabel dapat diubah kapan saja selama program berjalan. Contohnya:

<?php
$nama = "Ibnu Ahmad Fauzi";
echo "<h1>Selamat Datang, ", $nama, "</h1>";
$nama = "Budi Prakoso";
echo "<h3>Nama berubah menjadi, ", $nama, "</h3>";

Nilai lama akan ditimpa dengan nilai yang baru.

Sebelum lanjut ke materi berikutnya, dalam pembuata variabel ada aturan yang perlu diperhatikan:

  • Harus diawali dengan tanda $
  • Karakter pertama setelah $ harus berupa huruf atau garis bawah (_)
  • Tidak boleh mengandung spasi
  • Boleh mengandung angka
  • Tidak boleh menggunakan karakter khusus
  • Bersifat case sensitive, jadi $nama dan $Nama dianggap variabel yang berbeda

Walaupun PHP tidak mewajibkan gaya penamaan tertentu, programmer umumnya menggunakan salah satu konvensi berikut.

Camel Case

Huruf pertama menggunaka huruf kecil, sedangkan setiap kata berikutnya diawali huruf kapital.

$namaLengkap
$tanggalLahir
$jumlahSiswa

Snake Case

Setiap kata dipisahkan menggunakan garis bawah

$nama_lengkap
$tanggal_lahir
$jumlah_siswa

Dalam tutorial ini nantinya kita akan lebih sering menggunakan camelCase karena banyak digunakan pada framework modern seperti Laravel.



3.5. Dynamic Typing

PHP merupakan bahasa pemrograman yang menerapkan konsep Dynamic Typing, yaitu programmer tidak perlu menentuka tipe data suatu variabel secara menual. PHP akan mengenali tipe data secara otomatis berdasarkan nilai yang diberikan. Contohnya:

<?php
$nama = "Ibnu";
$umur = 25;
$tinggi = 170.5;
$aktif = true;

Pada contoh tersebut:

  • $nama bertipe string
  • $umur bertipe integer
  • $tinggi bertipe float
  • $string bertipe boolean

Dan untuk ngecek tipe datanya dalam keperluan debugging bisa menggunakan var_dump()

<?php
$nama = "Ibnu";
$umur = 25;
$tinggi = 170.5;
$aktif = true;

var_dump($nama);
echo "<br>";
var_dump($umur);
echo "<br>";
var_dump($tinggi);
echo "<br>";
var_dump($aktif);

3.6. Menggunakan Variabel di Website

Sekarang kita modifikasi website profil sebelumnya dengan memanfaatkan beberapa variabel, berikut contohnya:

<?php

$header = "<h1>Belajar HTML Dasar</h1><p>Website sederhana menggunakan Semantic HTML.</p>";
$footer = "<p>&copy; 2026 Belajar HTML Dasar</p>";

$judul = "Selamat Datang";
$artikel = "<article>
<p>Selamat datang di website sederhana yang dibuat menggunakan HTML.Website ini terdiri dari tiga halaman yang saling terhubung melaluimenu navigasi.</p>
<p>Seluruh struktur halaman menggunakan Semantic HTML agar kode lebihrapi dan mudah dipahami.</p>
</article>";
?>

<!doctype html>
<html lang="id">

<head>
  <meta charset="UTF-8" />
  <title>Beranda - Belajar HTML</title>
</head>

<body>
  <header>
    <?php echo $header; ?>
  </header>

  <nav>
    <a href="index.php">Beranda</a> |
    <a href="pages/profil.php">Profil</a> |
    <a href="pages/kontak.php">Kontak</a>
  </nav>

  <main>
    <section>
      <h2><?php echo $judul; ?></h2>

      <?php echo $artikel; ?>

    </section>

    <aside>
      <h3>Menu Cepat</h3>

      <ul>
        <li>Beranda</li>
        <li>Profil</li>
        <li>Kontak</li>
      </ul>
    </aside>
  </main>

  <footer>
    <?php echo $footer; ?>
  </footer>
</body>

</html>

Jangan lupa nama filenya diganti ke ekstensi .php.
