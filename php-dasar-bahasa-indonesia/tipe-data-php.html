#4. Tipe Data

4.1. Pengertian Tipe Data

Tipe data adalah klasifikasi suatu nilai yang menunjukkan jenis data yang disimpan di dalam sebuah variabel. Dengan adanya tipe data, PHP dapat mengetahui bagaimana suatu nilai diproses, disimpan, maupun ditampilkan.

Sebagai contoh, nama seseorang disimpan sebagai teks (string), umur disimpan sebagai bilangan bulat (integer), sedangkan nilai rata-rata dapat disimpan sebagai bilangan desimal (float).

PHP merupakan bahasa pemrograman yang menerapkan konsep dynamic typing, sehingga tipe data tidak perlu ditentukan secara manual ketika membuat variabel. PHP akan menentukan tipe data secara otomatis berdasarkan nilai yang diberikan.

Contohnya:

<?php

$nama = "Ibnu Ahmad Fauzi";
$umur = 25;
$tinggi = 170.5;
$aktif = true;

Pada contoh di atas:

  • $nama bertipe string
  • $umur bertipe integer
  • $tinggi bertipe float
  • $aktif bertipe boolean


4.2. Jenis-Jenis Tipe Data PHP

Secara umum, PHP memiliki delapan tipe data utama, yaitu:

No Tipe Data Keterangan
1 String Menyimpan teks atau karakter
2 Integer Menyimpan bilangan bulat
3 Float (Double) Menyimpan bilangan pecahan
4 Boolean Menyimpan nilai benar atau salah
5 Array Menyimpan kumpulan data
6 Object Menyimpan objek dari sebuah class
7 NULL Menunjukkan variabel tidak memiliki nilai
8 Resource Menyimpan referensi terhadap sumber daya eksternal

Selain itu, PHP juga mengenal tipe Callable, yaitu tipe khusus yang mempresentasikan fungsi atau method yang dapat dipanggil sebagai callback.



4.3. String

String adalah tipe data yang digunakan untuk menyimpan teks atau kumpulan karakter. String dapat ditulis menggunakan tanda kutip tunggal (' ') maupun kutip ganda (" ").

Contohnya:

<?php

$nama = "Ibnu Ahmad Fauzi";
$alamat = 'Kabupaten Blitar';

echo $nama;
echo "<br>";
echo $alamat;

Hasilnya:

Gambar 4.1 : contoh output string


String dapat berisi huruf, angka, simbol, maupun karakter khusus. Contohnya:

<?php

$nama = "Ibnu Ahmad Fauzi";
$alamat = 'Kabupaten Blitar';
$kode = "BNBWT-2025";
$website = "fauzidleware.vercel.app";



4.4. Integer

Integer merupakan tipe data yang digunakan untuk menyimpan bilangan bulat tanpa angka di belakang koma.

Contohnya:

<?php

$umur = 26;
$tahun = 2026;
$stok = 150;

echo $umur;
echo "<br>";
echo $tahun;
echo "<br>";
echo $stok;

Hasilnya:

Gambar 4.2 : contoh output integer


Integer dapat bernilai positif maupun negatif. Contohnya:

<?php

// integer positif
$harga = 100000;

// integer negatif
$saldo = -50000;



4.5. Float (Double)

Float digunakan untuk menyimpan bilangan pecahan atau desimal.

Contohnya:

<?php

$tinggi = 170.5;
$berat = 65.8;
$nilai = 89.75;

echo $tinggi;
echo "<br>";
echo $berat;
echo "<br>";
echo $nilai;

Hasilnya:

Gambar 4.3 : contoh output float


Tipe data float biasanya digunakan pada:

  • Nilai ujian
  • Harga barang
  • Berat badan
  • Tinggi badan
  • Perhitungan ilmiah

Penulisan koma dalam bilangan desimal tipe data float tidak dengan tanda koma biasanya, tapi dengan tanda titik .. Contohnya bukan 3,14 tapi yang benar 3.14.



4.6. Boolean

Boolean merupakan tipe data yang hanya memiliki dua kemungkinan nilai.

  • true
  • false

Boolean lebih sering digunakan dalam percabangan. Contohnya:

<?php

$login = true;

if ($login) {
    echo "Selamat datang";
}



4.7. Array

Array merupakan tipe data yang digunakan untuk menyimpan banyak data dalam satu variabel.

Contohnya:

<?php

$buah = ["Apel", "Jeruk", "Mangga", "Rambutan", "Jambu"];

echo $buah[4];

Array akan dibahas lebih mendalam pada bab tersendiri.



4.8. Object

Object merupakan hasil dari sebuah class pada konsep Object Oriented Programming (OOP).

Contoh sederhana:

<?php

class Mahasiswa
{
    public $nama = "Ibnu Ahmad Fauzi";
}

$data = new Mahasiswa();
echo $data->nama;

Object akan dipelajari secara lengkap pada materi OOP.



4.9. NULL

NULL menunjukkan bahwa suatu variabel tidak memiliki nilai. NULL sering digunakan untuk:

  • Mengosongkan variabel
  • Menandai data yang belum diisi
  • Menunjukkan tidak adanya nilai


4.10. Resource

Resource merupakan tipe data khusus yang digunakan untuk menyimpan refernsi terhadap sumber daya eksternal yang dikelola oleh PHP, seperti koneksi database, file yang sedang dibuka, atau stream jaringan.

Pada PHP modern, beberapa ekstesi telah mengganti penggunaan resource dengan objek, namun konsep ini masih penting untuk dipahami.

Contoh penggunaannya:

<?php

$file = fopen("data.txt", "r");

var_dump($file);

Output yang muncul akan menunjukkan bahwa variabel tersebut bertipe resource (atau objek pada ekstensi tertentu).



4.11. Callable

Callable adalah tipe data yang merepresentasikan fungsi, method, atau objek yang dapat dipanggil layaknya sebuah fungsi.

Contohnya:

<?php

function sapa()
{
    echo "Hello, World!";
}

$fungsi = "sapa";

$fungsi();

Callable banyak digunakan pada callback function, event, maupun framework modern.



4.12. Mengecek Tipe Data

PHP menyediakan beberapa fungsi untuk mengetahui tipe data suatu variabel.

<?php

$nilai = 90;
$nama = "Ibnu Ahmad Fauzi";
$ipk = 3.6;
$aktif = true;
$matkul = ["Pemrograman Berorientasi Objek", "Sistem Operasi", "Simulasi Digital"];

echo gettype($nilai);
echo "<br>";
var_dump($nilai);
echo "<br>";
var_dump(is_string($nama));
echo "<br>";
var_dump(is_int($nilai));
echo "<br>";
var_dump(is_float($ipk));
echo "<br>";
var_dump(is_bool($aktif));
echo "<br>";
var_dump(is_array($matkul));



4.13. Konversi Tipe Data (Type Casting)

Dalam kondisi tertentu, kita perlu mengubah suatu tipe data menjadi tipe data lain.

Contoh mengubah string menjadi integer:

<?php

$angka = "100";
$hasil = (int) $angka;

var_dump($hasil);

Atau mengubah integer menjadi string:

<?php

$angka = 100;
$hasil = (string) $angka;

var_dump($hasil);

Beberapa tipe casting yang sering digunakan:

  • (int)
  • (float)
  • (string)
  • (bool)
  • (array)
  • (object)
