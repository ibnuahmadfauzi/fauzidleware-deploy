#1. Mengenal PHP

1.1. Apa itu PHP ?

PHP merupakan singkatan dari PHP: Hypertext Preprocessor, yaitu sebuah bahasa pemrogramana yang dirancang khusus untuk membangun aplikasi berbasis web. PHP termasuk bahasa pemrograman server-side, artinya seluruh kode PHP diproses terlebih dahulu oleh server sebelum hasilnya dikirimkan ke browser pengguna.

Awalnya PHP dikembangankan oleh Rasmus Lerdorf pada tahun 1994 sebagai sekumpulan skrip sederhana untuk mengelola halaman web pribadi. Seiring perkembangan teknologi, PHP berkembang menjadi salah satu bahasa pemrograman web paling populer di dunia dan digunakan oleh berbagai website besar. Beberapa website yang menggunakan PHP antara lain:

  • Facebook (pada awal pengembangannya)
  • WordPress
  • Wikipedia
  • Joomla
  • Drupal
  • Moodle

Saat ini PHP juga menjadi dasar berbagai framework populer seperti Laravel, CodeIgniter, Symfony, dan Yii.

PHP memiliki banyak keunggulan, diantaranya:

  • Gratis dan bersifat open source
  • Mudah dipelajari oleh pemula
  • Mendukung hampir semua sistem operasi
  • Kompatibel dengan berbagai web server
  • Memiliki komunitas yang sangat besar
  • Mendukung banyak jenis database
  • Menjadi dasar dari framework Laravel yang banyak digunakan di industri


1.2. Cara Kerja PHP

Berbeda dengan HTML yang langsung dibaca oleh browser, file PHP harus diproses terlebih dahulu oleh server. Alur kerjanya sebagai berikut:

  1. Pengguna membuka halaman website melalui browser
  2. Browser mengirimkan permintaan (request) ke server
  3. Server menerima permintaan tersebut
  4. Mesin PHP mengeksekusi seluruh kode PHP
  5. Jika diperlukan, PHP mengambil data dari database
  6. PHP menghasilkan halaman HTML
  7. Server mengirimkan hasil HTML ke browser
  8. Browser menampilkan halaman kepada pengguna

Dengan kata lain, browser tidak pernah melihat kode PHP, melainkan hanya menerima hasil akhirnya berupa HTML, CSS, JavaScript, gambar, atau file lainnya.



1.3. Client vs Server

Dalam pengembangan web, terdapat dua komponen utama, yaitu client dan server.

Client

Client adalah perangkat yang digunakan oleh pengguna untuk mengakses website. Contohnya:

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Safari

Tugas client adalah:

  • Mengirim permintaan ke server
  • Menampilkan halaman web
  • Menjalankan HTML
  • Menjalankan CSS
  • Menjalankan JavaScript

Server

Server merupakan komputer yang menyediakan layanan kepada client. Tugas server antara lain:

  • Menjalankan program PHP
  • Mengakses database
  • Mengelola file
  • Memproses login
  • Menghasilkan halaman web

Contoh web server:

  • Apache
  • Nginx
  • LiteSpeed


1.4. Request dan Response

Website bekerja menggunakan mekanisme komunikasi antara browser dan server.

Request

Request adalah permintaan dari browser menuju server. Contoh request:

  • Membuka halaman web
  • Login
  • Mengirim formulir
  • Mengunggah file

Response

Response adalah jawaban dari server kepada browser. Isi response dapat berupa:

  • HTML
  • CSS
  • JavaScript
  • JSON
  • Gambar
  • Video
  • File PDF

Sebagai contoh, ketika pengguna membuka halaman http://localhost/index.php, browser mengirimkan request ke server. Server menjalankan file index.php, memproses seluruh kode PHP di dalamnya, kemudian mengirimkan response berupa halaman HTML yang ditampilkan di browser.



1.5. Instalasi PHP

Ada beberapa cara untuk menggunakan PHP pada komputer. Namun untuk tutorial ini kita akan menggunakan paket instalasi dari XAMPP. Paket tersebut berisi:

  • Apache
  • PHP
  • MariaDB/MySQL
  • phpMyAdmin

Kelebihannya:

  • Mudah dipasang
  • Cocok untuk pemula
  • Banyak digunakan dalam pembelajaran

Langkah Instalasi:

  1. Buka website apachefriends.org
  2. Unduh XAMPP sesuai sistem operasi
  3. Jalankan installer
  4. Pilih komponen Apache dan MySQL
  5. Selesaikan proses instalasi
  6. Buka XAMPP Control Panel
  7. Jalankan Apache
  8. Jalankan MySQL

1.6. Struktur Sederhana Project PHP

Sebuah project PHP sederhana biasanya memiliki struktur seperti berikut:

belajar-html/
│
├── assets/
│   ├── css/
│   ├── js/
│   └── images/
│
├── include/
│   ├── header.php
│   └── footer.php
│
├── pages/
│   ├── profil.html
│   └── kontak.html
│
├── index.php
└── about.php

Penjelasan:

  • assets/ menyimpan CSS, JavaScript, gambar, dan file pendukung lainnya
  • includes/ berisi file yang digunakan berulan, seperti header dan footer
  • pages/ berisi halaman-halaman website
  • index.php merupakan halaman utama yang pertama kali diakses


1.7. Praktik Sederhana

Buat folder dengan nama belajar-php di dalam lokasi C:\xampp\htdocs\. Lalu buat fle index.php di dalam folder C:\xampp\htdocs\belajar-php dan isi dengan kode berikut:

<?php
echo "Hello, World!";

Lalu buka web browser dan kunjungi url: http://localhost/belajar-php/
